SQAWE ADMIN RELEASE

Before deploying, add this Railway Variable:

SQAWE_OWNER_ID=<your numeric Telegram user id>

The owner gets Admin Panel automatically.
The owner can grant/revoke admin to other users.
Admins can verify users, suspend users, delete user posts, and open profiles.
Only the owner can grant/revoke admin.
The owner cannot be suspended or have the owner role removed.

Admin Panel appears only for users with admin access.

The verification badge is stored on the user and is shown next to names across Sqawe.
